# 错误回避知识库

以下是全系统历史执行中积累的经验教训。所有 agent 共享此知识。
执行任务时优先采用这些已验证做法。

## 其他错误（已发生 849 次）

- 检查上次方法是否可行，考虑简化或换一种方式

## 执行超时（已发生 283 次）

- 先输出最关键的结果，控制搜索范围
- 复杂任务拆成小步骤分别完成

## 路径缺失（已发生 281 次）

- 先用 glob 确认目标路径存在，再按发现路径操作
- 检查 contract 中指定的 output 路径是否正确
